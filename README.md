JUST OPEN CYBERSADHYA FILE COPY WHOLE TEXT PASTE IN ARDUINO.EXE AND UPLOAD 


# COMPONENTS
1. ESP32 WROOM
2. OLED 0.98"
3. BUTTON
4. BUZZER

# COMPLETE WIRING
  OLED → ESP32
1.VCC	3V3
2.GND	GND
3.SDA	GPIO 21
4.SCL	GPIO 22

  Push button → ESP32
  1.GPIO 27
  2.GND

    Buzzer → ESP32
1.+	GPIO 25
2.−	GND
